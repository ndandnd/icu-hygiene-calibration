\paragraph{Runtimes.} Cluster production used Linux with Python 3.12.3, NumPy
1.26.4 and Mesa 1.2.1; local runs used macOS arm64 with Python 3.12.2 and the
same package versions (Section~\ref{sec:s-stability} gives the platform mixture
of each study).
\begin{itemize}
\item \emph{Alternative-workflow study.} The production selection and analysis
ran in the pinned runtime on the cluster. After collection, the frozen code
reproduced the selection (636 fields) and analysis (139 fields) bitwise on macOS
and a blind reimplementation agreed (Section~\ref{sec:s-alt-verification}); five
full-horizon records were re-simulated byte-identically on macOS. These are
cross-platform checks; no exact-runtime replay was made after collection, and
the frozen analyzer refused the local runtime.
\item \emph{Alternative-workflow coefficient study.} All 256 records ran on macOS
(CPython 3.12.2, NumPy 1.26.4, Mesa 1.2.1), whereas the original-workflow
coefficient records came from the cluster (Linux, Python 3.12.3) and a local
machine. In original mode the adapter reproduced archived records bitwise on 10
seeds (8 in Gate 1 and 2 by the reviewer). Five of these had been produced on the
cluster (seeds 4018965857, 2050894151, 154101125, 2312492055 and 576264056) and
are the cross-platform evidence; the other five were macOS-to-macOS. The
alternative mode was not tested across platforms. The frozen-tree bytecode was
unchanged after all runs and all frozen hashes verified.
\item \emph{Measurement study.} macOS, Python 3.12.2, NumPy 1.26.4, SciPy 1.13.1,
with its own receipt; the runner refuses to overwrite a run.
\end{itemize}

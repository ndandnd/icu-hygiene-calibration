\subsection{Provenance and the execution amendment}\label{sec:s-alt-provenance}
A separate provenance review recomputed every check from the collected files and
the frozen tree, and accepted the study with caveats about evidence class and
wording.
\begin{itemize}
\item \emph{Freeze chain.} The original freeze, the amended freeze and the
derived policy freeze recompute exactly; no frozen scientific file changed.
\item \emph{Execution amendment.} The first replay probe failed after 5 seconds
in the launcher's executable-identity guard, before any model ran, because the
compute host's Python binary differed from the login host's. The two dependent
jobs were cancelled with zero elapsed time and no record existed. One documented
amendment, written between 20:41 and 20:48 UTC, changed only provenance and
runtime gates in five files (15 scientific functions are AST-identical); the
first scientific record appeared at 20:53 UTC. It anchored both production banks
to the successful compute-probe receipt, restricted execution to one compute
host and allowed exactly one replacement probe, which passed. The amendment
review was not blind and took about 12 minutes; its acceptability rests on the
independent hash and AST recomputation.
\item \emph{Runtime.} All 3,072 records come from one compute-host Python build
and package set (Linux, Python 3.12.3, NumPy 1.26.4, Mesa 1.2.1), equal to the
passing probe. The login-host and compute-host binaries differ, as the amendment
permits; no simulation, selection or analysis ran under the login-host binary.
\item \emph{Cross-platform spot check.} Five production records (two grid, three
policy, one per profile at the selected $p$) were re-simulated with the frozen
code on macOS (Python 3.12.2) and were byte-identical to the cluster records
after removal of runtime fields. This covers 5 of 3,072 records and is not an
exact-runtime replay.
\item \emph{Seeds.} Seeds are a fixed function of labels, mutually disjoint
across grid, policy and probe, and none of the 643 appears among 4,400 seeds of
locally archived prior studies (banks held only on the cluster were not checked).
\item \emph{Order and restarts.} Selection was queued with a scheduler dependency
before any outcome existed and used only the complete grid bank; policy and
analysis were dispatched by the selection job. There is no evidence of any
restart, but this is inferred from files (progress receipts, logs and lock
times), because no terminal scheduler accounting was collected.
\item \emph{Compute.} 167.5 of 768 allowed worker-hours (66.4 grid, 101.05
policy), peak concurrency 16, no overlap between phases.
\end{itemize}

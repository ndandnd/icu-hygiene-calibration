# Reproducing the ICU confirmation study

The release preserves all 5,248 records: 384 baseline-only runs, 256
transmission-free histories and 4,608 paired intervention runs. Every declared
seed and condition is retained, including failed matching and precision checks.
Each paired record contains control and policy outcomes, so record counts are
not counts of individual simulated branches.

`release_spec.json` lists the exact four scientific groups and supporting
files. The release manifest records every payload and chunk hash. Source,
configuration, analysis and coefficient-aggregation freezes predate the
corresponding results. Files are explicitly selected; clinical inputs, private
execution state, logs, credentials and infrastructure paths are excluded.

## Restore the archive

From the repository root, use a fresh destination:

```sh
python research/full_icu_confirmation_2026-10-08/freeze_release.py verify \
  --release research/full_icu_confirmation_2026-10-08/public_release
python research/full_icu_confirmation_2026-10-08/freeze_release.py restore \
  --release research/full_icu_confirmation_2026-10-08/public_release \
  --output restored_confirmation
```

The utility rejects unsafe paths, duplicate or missing members, altered hashes
and an existing restoration destination. Each compressed chunk is below
20 MiB. Prior study archives are separate and remain unchanged.

## Recompute the saved analysis

Use Python 3.12 and the included `requirements-lock.txt`. Run within the restored
repository. The exact module-specific commands are recorded in
`RELEASE_PREPARATION.md`; each analyzer reads only complete restored banks and
writes a new replay directory. Do not rebuild the locked design or overwrite
the original reports.

The calibration, holdout and environmental analyses use the frozen
`analyze.py`, 200,000 whole-seed bootstrap draws and the declared bootstrap seed.
The holdout reads the original calibration selection; it never refits a
probability. The bridge aggregation combines the exact 38 declared partitions
and writes both its summary and provenance binding. No replay requires new
simulations.

Independent original-bank audits recomputed every reported scientific field
with the frozen analyses. The final release verification records separately
whether restored analyses and source assembly reproduce byte for byte. Exact
file preservation and cross-platform numerical agreement are distinct checks;
the verification report identifies any tolerance used.

## Figures and documents

The production figure CLI is in `figures/DESIGN.md`. Use the archived complete
reports and freezes as inputs, writing to a fresh output directory. The sole
new numerical calculation in the figure builder is the displayed leading rate,
1,000 times p squared times mean K divided by mean transmission-free exposure.
Its input means and measured comparisons are retained in the nine-row CSV.

The manuscript and guide assembly CLIs are in their respective
`CONFIRMATION_INTERFACE.md` files. They validate report and figure hashes before
inserting the supplied prose. The manuscript has two source outputs: the main
paper and an uncompiled fragment retaining the earlier experiment tables.
Only the main source is a standalone document. The guide additionally reads
`guide/outcomes_confirmation.json`; no outcome paragraph is generated by a
statistical fitting routine.

Compile `main.tex` independently. The desktop compiler checks the canonical
source; the reading PDF is exported separately and visually reviewed.
For the guide, use `requirements-guide.txt` and the documented font fallback.
Original PDF bytes are preserved. A new PDF can differ because of fonts,
metadata or rendering software even when its numerical content agrees.

## Interpretation

Baseline matching was not established under the six declared interval checks.
The reported profile contrasts concern the fixed configurations. No result is
a clinical estimate of infections, deaths or the causal effectiveness of a
hospital intervention. The finite-horizon small-transmission expansion is not
a finite-probability error certificate for these simulations.

# Source reconstruction for the opportunity-rule and surface follow-up

This source-only bundle reconstructs the preserved humanized manuscript and supplement with the completed six-contrast follow-up. It copies the original weekly figure unchanged. It does not run simulations, recompute the bootstrap, compile a PDF, install canonical files, or certify clinical assumptions.

Use Python 3.10 or later with its standard library. Obtain the source-binding manifest identity from the separately verified release acceptance, then run from this directory:

```sh
python3 -B reconstruct.py --bundle . --expected-identity TRUSTED_MANIFEST_IDENTITY --output ../reconstructed_sources
```

The output must be fresh and outside this bundle. The adapter checks its own source, the exact builder, all bound inputs and their inventory, actual numerical/scientific acceptance predicates, and all six expected output hashes. It reconstructs manuscript.tex, supplement.tex, the source-relative figures/weekly_control.png, readable source diffs and SOURCE_MANIFEST.json, then adds a source-only RECONSTRUCTION_RECEIPT.json. Compile the reconstructed sources using the separately documented presentation environment; PDF layout acceptance is independent of this adapter.

The scientific scope review is exact separately sealed bytes.

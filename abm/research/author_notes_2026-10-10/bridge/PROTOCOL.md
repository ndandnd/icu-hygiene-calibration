# Author-note p=0 coefficient sensitivity replay

Prepared 10 October 2026. This module deterministically replays exactly the **same 256 original p=0 seeds/backgrounds** from the completed 8 October study. It does not draw a new epidemiological sample. Do not launch without the parent study freeze. Old sources, results, and canonical manuscript are read-only.

The base background is fixed at h=.90, rho=0, e=1, clean hands/sites, 3% imported carriage, `zone_separate`, the frozen 30-bed/staffing/topology model, 233280 warmup and 145152 observation ticks. The copied adapter preserves original RNG consumption and event digest bytes. Every seed must reproduce the original ordered event hash, total event counts, exposure/admission statistics, and complete coefficient summaries for the three original profiles bit for bit before publication.

All comparisons share that original background. Evaluate the .90→.95 grid rho={0,.25,.5,.75}, e={1,.9,.8,.6}, plus three original profiles (rho,e)={(0,1),(.5,1),(0,.8)} at .80→.90 and .95→.99: **22 comparisons/44 coefficient arms**. Each comparison has its own coefficient warmup/control h0 and post-warmup policy h1, independently of the base background hygiene parameters. Initialized completion memory, warmup pickups, resets, isolation weights and actual opportunity order are retained. There is no positive-p pathwise coupling assertion.

Compute unweighted same-worker carrier-contact-to-observed-susceptible-contact bridge counts in exact bins 0..12 plus an exact >=13 aggregate tail, once per replay. These raw counts ignore isolation weights and hygiene survival. Preserve original six weighted coarse histograms (0,1,2,>=3) for reconciliation. Count **observation-period** opportunities, patient contacts, surface contacts and resets by worker role Nurse/Dr/XrayDr. Events exactly after warmup are observed (`total_ticks > warmup_ticks`). No event traces are stored.

The seed-level output includes all paired coefficients, warmup contributions, original reconciliation evidence, ordered event digest, raw histogram, and role counts. The response is 1−mean(K1)/mean(K0), undefined when mean(K0)=0. Do not average seed ratios or exclude zero seeds. Runner summaries are descriptive normal/delta Monte Carlo diagnostics conditional on this fixed background bank. Parent downstream analysis may provide a declared vector bootstrap preserving the old A/B bank labels and all within-background covariance; no joint directional conclusion across the 22 comparisons is authorized by pointwise intervals.

`reference_index.json` binds original completed-record bytes and portable ABM-root-relative paths. Runtime manifests bind fixed science, config, implementation, protocol, original source hashes, frozen core hashes, input record hashes and runtime versions. Changed seeds, science, source, input records, or runtime cannot silently resume an existing scope. The source modules can be imported as package modules or executed as standalone scripts; no absolute deployment paths are required.

`array_worker.py --config bridge/config_all.json --output RESULTS --task-index I --task-count 32 --wall-seconds 3300` executes `seeds[I::32]` and writes `RESULTS/part_II` (8 seeds, 4A+4B per task). Freeze with the same command plus `--freeze-only`. The parent orchestrator verifies its outer freeze before and after execution. Each partition has one exclusive lock. Seed records publish atomically after complete simulation and validation; partial seeds restart from initialization. SIGTERM/SIGUSR1/SIGINT and wall time exhaustion return 75; fatal scientific/input validation failures return 2 in the array entrypoint. A hard kill may leave a replaceable `.tmp` file but never a complete partial seed. Immutable outputs refuse conflicting writes.

Use one CPU per worker. Maximum per-invocation wall budget is 3300 seconds; the scheduler may allocate longer wall time to allow bounded retries in the same fixed partition. No new seeds, replacement seeds, altered horizon, positive-p runs, or event-trace storage. Unit tests and benchmark are explicitly tiny; no full-horizon local validation is required.

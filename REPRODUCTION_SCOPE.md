# Reproduction scope

Portable standard-library checks: exact binary-history enumeration and counterexamples; worker pooled-coefficient algebra; original and expanded supplement table generation. They read only deposited source/numerical files and require no ICU simulation or clinical data. Exact proof checker omits only the private editorial-source hash lookups from its original implementation; all mathematical tests are retained.

Raw-record numerical reanalysis: all 17,920 completed synthetic records and their original per-bank manifests are deposited. The expanded coefficient independent implementation reads its 256 records and the deposited seedbook/assay inputs; it can repeat the recorded estimates and bootstrap without running the model. These longer numerical paths were not rerun during this release assembly. Undefined estimates, failed gates, failed baseline tests and failed predictions remain in saved outputs.

Archived simulations: exact original frozen CPEmodel/agents/routes and bridge/workflow dependencies are included, as are current maintained scientific modules. Individual source/config/seed bindings are preserved. The original records may carry historical absolute provenance paths; full provenance analyzers that dereference them require explicit remapping to the public extraction tree. This deposit does not claim that every historical launcher, scheduler adapter or full simulation pipeline is portable unchanged. Private cluster transfer material and transport duplicates are intentionally excluded. The portable commands above are the tested entry points.

The frozen historical README/protocol files describe their own dates and draft status. The root README and current paper give the current authorship, title and declarations. No clinical spreadsheets, private reviews/correspondence, credentials or old repository history are part of the release.

This v1.0.2 repository is a code and synthetic data deposit. Generated scientific plots/tables and standalone technical extracts under `execution_records/` are included; complete paper/Supplementary Information PDFs, complete manuscript TeX snapshots, and full-source diffs are excluded. Historical machine maps are retained unchanged and may name those excluded inputs or their original archive locations. The execution index explains the path mapping. Separate preprint dissemination is planned, with no public preprint URL asserted here.

The author explicitly authorized publication of the technical reproducibility report and archived full grid in v1.0.2. Its PDF and standalone source closure are included. Main manuscript/core supplement PDFs and source snapshots remain excluded. No simulation, analysis grid or numerical estimate was rerun or changed for this editorial release.
